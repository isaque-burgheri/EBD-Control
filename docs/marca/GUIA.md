# Marca — EBD Controle

**Conceito:** um livro aberto (a Palavra) com um check em verde-limão saindo da lombada
(a chamada feita). Uma ideia só: estudo + presença.

## Cores
| Uso | Nome | HEX |
|---|---|---|
| Fundo do ícone | Preto quente | `#1A1615` |
| Check / acento | Verde-limão | `#DBFFA5` |
| Página esquerda | Papel | `#F6F2EA` |
| Página direita | Papel sombra | `#E0D9C8` |

## Arquivos
- `simbolo.svg` — mestre colorido (ladrilho arredondado 256×256).
- `simbolo-preto.svg` / `simbolo-branco.svg` — uma cor, para impressão e fundos fotográficos.
- `icone-512.png` — ícone para loja/site; `favicon.ico` / `favicon.svg` — site (GitHub Pages).
- No app: `app/src/main/res/drawable/ic_launcher_foreground.xml` (o fundo é `ic_launcher_background`).

## Uso
- Espaço livre ao redor: no mínimo a largura do check (22 unidades de 256, ≈ 9% do lado).
- Tamanho mínimo: 24 px de lado. Abaixo disso use só o ladrilho com o check.
- Não aplicar gradiente, sombra, nem trocar o limão por outra cor.
- Sobre fundo claro use o ladrilho preto inteiro (o limão some sobre branco).
